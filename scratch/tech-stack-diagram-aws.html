Nervve target-state architecture on AWS, in one picture.

Schematic of the production stack from ADR 0004 (AWS variant) — where a request enters, how identity gates it, where the event bus sits, which paths are safety-critical (one-way dispatch, CloudHSM-signed commands, Merkle-anchored settlement), and which are advisory (ML recommendations that never issue directly). Supersedes ADR 0003 (GCP variant).

Legend

Standard component. A service, gateway, or store on the platform.
Security-critical or Rust component. Dispatch, matching, HSM, WORM, TSA — the paths and stores that carry the platform's deepest promises.
Trust boundary. Dashed containers mark cloud, VPC, and OT-zone edges.
Solid navy arrow. Request or data flow.

Dashed Corten arrow. Advisory — ML recommendations that never issue commands directly.
Dashed muted arrow. Event publish / consume through Kafka; derived-store fan-out.

Claims the diagram makes

  • Zero-trust at the identity boundary. Every downstream call carries a signed, verified, short-lived credential — including calls originating inside the VPC.
  • Rust for two codepaths. Matching and dispatch are the latency- and correctness-critical services; the language pick is a visible design decision, not an accident.
  • MSK is the spine. Aurora holds aggregate state; MSK holds the sequence of events. Timestream, TimescaleDB, and S3+Iceberg are all rebuildable derivations.
  • Dispatch is one-way. Commands cross a purpose-built OT gateway outbound only (never AWS IoT Core); telemetry arrives on a separate, mediated channel. This is the IEC 62443 posture.
  • ML never issues commands. Models feed the deterministic dispatcher; the dispatcher decides. A model can be wrong; a wrong dispatch cannot happen because of one.
  • Settlement is independently verifiable. Every closed window produces a Merkle root, CloudHSM-signed and TSA-anchored, stored on S3 with Object Lock. Counterparties do not have to trust the platform to verify a trade.
  • Security Lake sees everything, IaC is the only production path. Security Lake + GuardDuty ingest all logs and threat signals; Terraform + AWS CodeDeploy is the only route to production — no click-ops, ever, enforced by SCPs.
